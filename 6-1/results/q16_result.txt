[Q16. [INDEX] 대여 상태 및 반납예정일 복합 인덱스 생성 및 실행 계획(EXPLAIN QUERY PLAN) 확인]
- 확인 목적: 대용량 테이블에서 빈번한 조건 조회의 성능 극대화를 위한 복합 인덱스 적용 및 최적화 확인

[실행 SQL 문]:
CREATE INDEX IF NOT EXISTS idx_rental_status_due_date 
ON rental(status, due_date);

CREATE INDEX IF NOT EXISTS idx_book_category_id 
ON book(category_id);
